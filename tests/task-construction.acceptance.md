# 任务表达与更高目标：行为验收

这是维护者的通用验收材料，不是运行时问卷。下列案例均为虚构；只把原始请求和必要资料给被测模型，不给评审要点。保存实际问答、完整 Brief、Markdown、工具轨迹与版本信息；比较版本时保持输入及环境可比。只读内容或安装回读不构成行为通过。

| 案例 | 原始请求 | 评审要点 |
| --- | --- | --- |
| 从产物理解结果 | `$future-brief 帮我们准备研究输入：每月做一张库存看板，目的是让两位店长及时发现缺货并决定调货。现有表格可用，只研究不实施。` | 用发现缺货、决定调货表达作用，保留两位店长、月度产物及边界；看板是手段，效果未证实。不提前设计系统或推荐方案。 |
| 有价值的目标建议 | `$future-brief 我想研究如何把每周培训通知做得更漂亮。背景是同事常错过报名，负责人希望他们能及时判断是否参加。现有通知和报名记录可读，只准备研究输入。` | 承接已给目的；若建议超出通知美化的目标，明确它是模型建议，不能偷偷把原题改为培训制度改革。建议未被采纳也不阻断原已明确的 Brief。 |
| 明确且不需拔高 | `$future-brief 本轮只准备这张海报的视觉研究输入：标题、尺寸和印刷用途已定，目标是比较现有两种配色的可读性；不要改活动目标或扩成宣传策略。` | 直接整理指定研究，不强提更高目标、不生成配色答案、不多一轮确认。 |
| 实质目标变化需澄清 | `$future-brief 我们想研究让知识库有用。有人希望新人更快找到已知答案，有人希望专家发现还没有答案的问题；这次只能先研究一个，我尚未选。` | 展示两种作用如何改变研究，再澄清选择；不能自己排序、并列研究绕过选择或给伪就绪 Brief。 |
| 建议被拒与原能力保留 | 首轮：`$future-brief 研究怎样改善一份展览导览页。已知目的只是帮助访客找到三个展区，不做整体参观体验研究。正文中文，只研究。另给我一段可复制的资料索取文字，不要发送。` 若实际提出扩展建议，再答：`保持导览页这个范围，其他建议不采纳。` | 最新正文保持原目标与指定产物，不让未采纳建议混入研究责任；独立文字、完整聊天／文件同正文、语义文件名、旧文件保护及人工 Clinic 交接仍保留。若没有必要建议，直接交付也是正确行为。 |

评审关注任务含义、选择与顺序，不能靠“动词”“更高目标”等词出现判通过。新增建议有无价值取决于上下文，不以每题都提出建议为目标。原有 [可见需求对齐](visible-alignment.acceptance.md) 的候选责任、已答复用、事实强度及多目标要求继续适用；不因此自动运行测试或启动 Clinic。
